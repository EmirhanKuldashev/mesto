# Модель данных

Все пространственные поля используют PostGIS и SRID 4326; координаты передаются как долгота, широта. Районы имеют `geometry` (MultiPolygon), `centroid` (Point), демографические поля и идентификатор источника. Поле `boundary` сохранено для совместимости с ЭТАПОМ 1. Геометрии демо-районов являются условными прямоугольниками и **не** являются административными границами.

| Таблица | Назначение |
| --- | --- |
| `districts` | Семь районов, геометрия, население, площадь и плотность |
| `pois` | Единый каталог существующей инфраструктуры: категория, подкатегория, точка, район, JSONB `metadata` |
| `residential_complexes` | ЖК, застройщик, класс, срок сдачи, стартовая цена, планировки JSONB |
| `property_offers` | Продажа: цена, площадь, комнаты, этаж, адрес, точка, район и ЖК |
| `rent_listings` | Аренда: месячная стоимость, площадь, комнаты, адрес, точка и район |
| `future_objects` | Планируемые объекты с годом, статусом, уверенностью и документом; не входят в `pois` |
| `mortgage_programs` | Ставка, лимит, первоначальный взнос, требования JSONB, регион и ссылка |
| `data_sources`, `source_versions` | Происхождение, версия, дата получения, контрольная сумма и число записей |
| `data_quality` | Полнота, свежесть, уверенность, доля прогноза и ограничения по записи |

Каждая импортируемая запись хранит `source_id`, `source_type`, `source_version`, `fetched_at`, период применимости и `is_synthetic`. Это позволяет сохранять несколько источников без привязки расчётов к конкретному сайту. Для текущих демо-записей `source_type=synthetic` и `is_synthetic=true`. Числовые демо-показатели, цены и ипотечные условия вымышлены; ими нельзя пользоваться для реальных решений.

Миграции: `0001_initial`, `0002_data_foundation`, `0003_spatial_aliases`. Команда: `alembic upgrade head`. API возвращает геометрию в GeoJSON и поддерживает `bbox=west,south,east,north`.
