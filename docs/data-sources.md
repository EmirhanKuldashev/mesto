# Источники данных

Сейчас доступны только synthetic данные `synthetic-districts`, `synthetic-poi`, `synthetic-real-estate`, `synthetic-future`, `synthetic-mortgage`. У них нет внешнего URL или лицензии; они служат для проверки схемы и API. `/api/data-sources` показывает дату, версию, число записей и контрольную сумму.

| Будущий источник | Данные | Условия подключения |
| --- | --- | --- |
| OpenStreetMap | POI, улицы, остановки, парки | Проверить лицензию ODbL, атрибуцию, актуальность и теги категорий |
| ДОМ.РФ и официальные источники | ЖК, ипотека, жилищные показатели | Проверить официальный доступ, регион, даты и права повторного использования |
| Площадки недвижимости и аренды | Предложения продажи и аренды | Использовать разрешённый API/выгрузку; удалять дубликаты, отслеживать снятые объявления |
| Муниципальные данные и генплан | Районы, планируемые объекты, транспорт | Сохранять документы, статус, дату и уровень уверенности; план не равен существующему объекту |
| Демография, экология, транспорт | Районные метрики и доступность | Хранить методику, единицы измерения, период и географическую детализацию |

До подключения реального источника требуется выяснить формат выдачи, лицензию, лимиты, частоту обновления и полноту покрытия Красноярска. Адаптер переводит данные в общие сущности и сохраняет provenance; API и будущая аналитика читают только нормализованные таблицы. Периодические загрузки должны создавать новую `source_version`, фиксировать `fetched_at`, `record_count`, checksum и оценки `data_quality`.
